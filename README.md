### 📌 Project Overview

This project is an **end-to-end Natural Language Processing (NLP)** application that automatically classifies news articles into different categories using Machine Learning techniques.

The goal is to build a reliable text classification model that can understand the content of a news article and predict its category accurately.

---

### 🎯 Key Features

- Data Cleaning & Preprocessing
- Text Normalization (Lowercasing, Removing punctuation, Stopwords)
- Feature Extraction using **TF-IDF** and **Bag of Words**
- Training multiple Machine Learning models
- Model Evaluation (Accuracy, Confusion Matrix, Classification Report)
- Ready-to-use classification pipeline

### 📂 Dataset

- **File**: `newsdata01.xls`
- Contains news articles with their corresponding categories
- Used for both training and testing the classification models

---

### ⚙️ Project Workflow

1. **Import & Explore** the dataset
2. **Clean** the text data (remove noise, special characters, etc.)
3. **Preprocess** text:
   - Lowercasing
   - Tokenization
   - Removing stopwords
   - Lemmatization / Stemming
4. **Feature Extraction**:
   - Bag of Words (BOW)
   - TF-IDF Vectorization
5. **Train** Machine Learning models (mainly Logistic Regression)
6. **Evaluate** model performance
7. **Predict** categories for new articles

---

- Confusion Matrix
- Classification Metrics (Accuracy, Precision, Recall, F1-Score)
