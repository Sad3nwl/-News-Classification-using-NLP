# 📰 News Classification using NLP

## 📌 Project Overview

This project is a Natural Language Processing (NLP) application that classifies news articles into different categories using Machine Learning techniques.

The project includes:
- Data Cleaning
- Text Preprocessing
- Feature Extraction
- Model Training
- News Classification

---

# 🚀 Technologies Used

- Python
- NLP
- Scikit-learn
- Pandas
- NumPy
- Jupyter Notebook

---

# 📂 Dataset

The dataset contains news articles and their categories used for training and testing the classification model.

---

# ⚙️ Project Steps

1. Import Dataset
2. Clean Text Data
3. Remove Stopwords
4. Text Vectorization (TF-IDF)
5. Train Machine Learning Model
6. Evaluate Model Performance

---

# 📊 Machine Learning Concepts Used

- TF-IDF
- Bag of Words
- Text Classification
- Confusion Matrix
- Logistic Regression
